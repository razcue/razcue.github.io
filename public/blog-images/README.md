# Blog Images

This folder contains images for blog posts:

- Hero images (displayed at the top of posts)
- OpenGraph images (for social media sharing)

## Naming Convention:

- `{post-slug}-hero.webp` - Hero image for post
- `{post-slug}-og.svg` - OpenGraph/social preview image

Example:

- `astro-changes-everything-hero.webp`
- `astro-changes-everything-og.svg`
