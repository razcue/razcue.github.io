# Resume Structure Guide

Standard sections for Rayko's resume.

## Section Order

1. **Header** - Name, title, contact
2. **Summary** - Brief professional statement (3-4 sentences)
3. **Education** - Degree, institution, dates
4. **Experience** - Most recent first
5. **Skills** - Technical + Soft分开

## Header

```
Rayko Azcue
Senior Full-Stack Developer
📍 Cuba (Remote) | 📧 razcue@yandex.com | 🔗 github.com/razcue
```

## Summary Template

```
Senior full-stack developer with {X}+ years of experience building scalable web applications.
Specializing in {primary_stack} with expertise in {secondary_skills}.
Demonstrated track record of {key_achievement_quantified}.
Passionate about performance optimization and clean code.
```

Customize summary to include keywords from job posting.

## Experience Section

### Entry Format

```
Company Name | Job Title
Location | Date Range

- Action verb + task + quantified result
- Action verb + task + quantified result
- Action verb + task + quantified result
```

### Bullet Guidelines

- 3-5 bullets per position
- Start with different action verbs
- Quantify when possible
- Most relevant bullets first

## Skills Section

```
Technical: {list_primary_tech}
Soft: {list_soft_skills}
```

## Formatting Rules

- Font: Times New Roman 11pt
- Margins: 1 inch
- No tables in experience
- No graphics/images
- Consistent date format
- ATS-readable PDF
