# Scoring Template

Use this template to score each company.

## Scoring Grid

| Criteria       | Weight | Score (0-10) | Weighted Score |
| -------------- | ------ | ------------ | -------------- |
| Active Hiring  | 30%    | \_           | \_             |
| Remote Policy  | 30%    | \_           | \_             |
| Tech Match     | 20%    | \_           | \_             |
| LATAM Friendly | 10%    | \_           | \_             |
| Growth Stage   | 10%    | \_           | \_             |
| **Total**      | 100%   | -            | **\_**         |

## Score Definitions

### Active Hiring (30%)

| Score | Description                               |
| ----- | ----------------------------------------- |
| 10    | Multiple recent postings, actively hiring |
| 7     | Recent posting (past 14 days)             |
| 5     | Some postings (past 30 days)              |
| 3     | Old postings, unclear if still hiring     |
| 0     | No clear hiring signals                   |

### Remote Policy (30%)

| Score | Description                                         |
| ----- | --------------------------------------------------- |
| 10    | Explicitly "remote worldwide", "work from anywhere" |
| 7     | "Remote" without US restrictions                    |
| 5     | "Remote first" or "distributed team"                |
| 3     | Hybrid mentioned, remote possible                   |
| 0     | On-site only or US-only                             |

### Tech Stack Match (20%)

| Score | Description                           |
| ----- | ------------------------------------- |
| 10    | Vue/Nuxt + TypeScript (primary stack) |
| 7     | React + TypeScript                    |
| 5     | Other relevant tech (Laravel, Node)   |
| 3     | Some overlap                          |
| 0     | No relevant tech                      |

### LATAM Friendly (10%)

| Score | Description                                        |
| ----- | -------------------------------------------------- |
| 10    | Explicitly mentions LATAM hiring or has LATAM team |
| 7     | Global team, mentions international hiring         |
| 5     | No restrictions mentioned                          |
| 3     | Somewhat unclear                                   |
| 0     | US-only signals                                    |

### Growth Stage (10%)

| Score | Description                  |
| ----- | ---------------------------- |
| 10    | Series B+, 100+ employees    |
| 7     | Series A or 50-100 employees |
| 5     | Growing, established         |
| 3     | Small startup                |
| 0     | Unknown or struggling        |

## Minimum Threshold

**Pass: Total >= 60**
**Fail: Total < 60**

Even with high scores, **ALWAYS skip if no contact email found**.
